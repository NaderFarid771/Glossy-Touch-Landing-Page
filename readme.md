# Glossy Touch — Glassmorphism Landing Page

A modern landing page concept featuring a glassmorphism-inspired design, translucent cards, soft gradients, and a responsive layout.

## Features

- Modern glassmorphism UI
- Dark background with colorful gradient effects
- Responsive layout for different screen sizes
- Feature cards with hover-friendly visual styling
- Hero section with an image
- About section and footer navigation

## Built With

- HTML5
- CSS3
